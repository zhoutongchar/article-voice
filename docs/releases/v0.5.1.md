# Article Voice 0.5.1 · Mac developer preview

Listen to Chrome articles with nine local voices, spoken-word highlighting on the original page, word-click seeking, and pitch-preserving playback up to 3×.

The player has three views: a thin single-row Minimal bar, Compact, and Full with voice/language settings. Follow words is available in every view. Manual scrolling pauses automatic following for ten seconds. Playback starts as passages are ready by default, with an option to prepare the whole article first.

## Downloads and installation

- **Article-Voice.zip** — the self-installing Mac app, bundled Python runtime, prepared voice references, and Chrome extension. Requires Apple Silicon and macOS 26 or later.
- **Article-Voice-Chrome.zip** — the extension alone for manual unpacked installation. The Mac app is still required for local voices.
- **SHA256SUMS** — SHA-256 checksums for both downloads.

Unzip the app, open it, and click **Install Article Voice**. First setup downloads **3.61 GB** of verified model files. Choose **Connect Chrome**, enable Developer mode in `chrome://extensions`, and use **Load unpacked** with:

```text
~/Applications/Article Voice.app/Contents/Resources/ChromeExtension
```

Then choose **Try a reading**. No Python installation or API key is needed.

This is an **ad-hoc signed, unnotarized preview**. If macOS blocks it, follow [Apple's guidance](https://support.apple.com/en-us/102445) for reviewing and opening a trusted downloaded app. There is no Chrome Web Store listing; Developer mode is required. See the [README](https://github.com/zhoutongchar/article-voice#install-the-preview) for installation, updates, privacy, and limitations.
